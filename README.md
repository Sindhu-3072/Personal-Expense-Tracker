# Personal Expense Tracker

## Project Description

A desktop-based Personal Expense Tracker built using Python, Tkinter, and SQLite. This application allows users to manage expenses, generate reports, and visualize spending patterns.

---

## Features

- User Registration and Login
- Secure Password Hashing
- Add Transactions
- Update Transactions
- Delete Transactions
- Search Transactions
- Category-wise Filtering
- CSV Export
- Monthly Expense Graph
- Pie Chart Analytics
- Reports Window
- Multi-user Support
- Logout System

---

## Technologies Used

- Python
- Tkinter
- SQLite
- Pandas
- Matplotlib
